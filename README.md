# travel-research / 4つ星ホテル価格ランキング

世界347都市の4つ星ホテル価格を、Booking.com の実勢価格から12ヶ月分サンプリングして集計したもの。

| `disclaimer.html` | 免責事項・調査方法・出典 |
| `privacy.html` | プライバシーポリシー（localStorage の用途を明記） |
| `about.html` | 運営者情報（運営者名・連絡先は未記入） |
| `page.css` | 上記3ページ共通のスタイル |
| `city/*.html` | 都市別ページ347枚（`tools/build-pages.js` の生成物。**手で編集しない**） |
| `country/*.html` | 国別ページ120枚（同上・生成物） |
| `tools/build-pages.js` | 都市・国ページと sitemap の生成スクリプト（正本は index.html の DATA） |

| `favicon.svg` | サイトアイコン |

## HTMLの操作

| 操作 | 結果 |
|---|---|
| レイアウト | 広い画面=左に一覧・右に地図を固定表示（追従）／1080px以下=地図が画面上部に固定 |
| 地図スタイルの切替 | 地図ヘッダーのセレクトで「標準（OSM・既定）」と「淡色（見やすい）」を切替。選択はブラウザに保存 |
| セクションジャンプ | 一覧上部の追従ナビ（価格帯の分布／ランキング／国・地域別／データと注意点）。たたまれたセクションは自動で開く。1080px以下では追従せず固定表示 |
| 表見出しの固定 | ランキングの見出しを複製して画面に固定（本物は .tablewrap の overflow により sticky が効かないため）。並べ替えは本物へ委譲。1080px以下・地図全画面では非表示 |
| 位置ジャンプ | ナビ2段目。ランキング内は50件ごと（1–50…301–347）、国・地域別は20件ごと（1–20…101–120）。絞り込み・並べ替えに追従して作り直され、50件（国は20件）以下では非表示 |
| 国ページへの導線 | 国・地域別セクションで国を開くと、上部に「◯◯の相場ページを開く →」 |
| 「詳細」リンク | 各行の右端。その都市の月別価格・最安時期・同国の他都市をまとめたページへ（Googleマップは地図の吹き出しと詳細ページから） |
| 「全画面」ボタン | 地図をウィンドウ全体に拡大（背景クリックまたは Esc で戻る） |
| 価格帯の分布カード | 選択月の価格で件数を集計し、クリックでの絞り込みも選択月基準（見出しに対象月を表示。欠測月は年間中央値で代替） |
| 地図マーカーの色 | 選択月の価格帯で着色（月セレクトに連動）。データのない月は年間中央値の色で代替。吹き出しに選択月の価格と年間中央値を併記 |
| 月セレクト＋対象月の価格列 | 1月〜12月から対象月を選択（既定＝今月・今月/来月には注記）。選んだ月の価格を列に表示し、グラフの青丸もその月に移動。列見出しクリックまたは並べ替えセレクトでその月の安い順/高い順に並べ替え。1〜9月は2027年・10〜12月は2026年の実測値 |
| 中国語圏の都市名 | アルファベットの後ろに漢字を併記（例 Guilin（桂林））。中国10都市・香港・マカオ・台湾2都市。検索も漢字でヒット |
| 月別推移グラフ | 左から1月→12月の暦順で表示（1〜9月=2027年・10〜12月=2026年の実測値）・緑の点=最安月・赤の点=最高月・青い丸＋点線=閲覧時点の月（端末の日付から自動判定・最安/最高と重なっても見えるよう中抜きリング）・カーソルを重ねると年月と価格をツールチップ表示（今月の位置では「・今月」と表示） |
| 各セクションの見出し | ランキング／国・地域別／データと注意点を個別に折りたたみ |
| 国・地域名クリック（ランキング） | その国だけに絞り込み（もう一度クリックで解除）・地図もその国にフォーカス |
| 列見出し「国・地域」/ 並べ替えセレクト | 国・地域順（五十音順、国内は安い順）に並べ替え |
| ☆ / ★（都市名の左・国・地域別の各国見出し） | 都市と国それぞれをお気に入り登録。★の都市は行の背景が薄い黄色に。並び順は一切変わらない。localStorageに保存され次回も維持 |
| 「★のみ」ボタン（ランキング上部） | ★の都市＋★の国に属する都市だけに絞り込み（地図も連動）・登録数を表示 |
| 表の列幅 | table-layout:fixed + colgroup（%指定）。並べ替え・絞り込みで動かず、画面幅に合わせて全列が収まる（横スクロール不要） |
| 並べ替え・絞り込み時のスクロール | ランキング見出しが画面外に出ている場合のみ、見出し位置へ自動で戻す |
| 都市名クリック（ランキング／国・地域別のどちらでも） | 毎回その都市の国に地図を合わせ直す（国全体が入る縮尺）・都市を波紋リングで強調・吹き出し・行ハイライト・国別セクションも連動して展開 |
| 国名クリック（国・地域別） | その国の都市だけを表示しズーム。国内の表はランキングと同項目（順位・月別推移・変動まで。国名列のみ重複のため省略） |
| 国表示中に他国の都市をクリック | その都市の国へ切り替えて表示 |
| 地図上部のバッジ | 常に1行固定（36px）で現在の表示範囲を表示・地図の位置は都市によって動かない。「全体に戻す」でフォーカス解除 |
| 国・地域別のセレクト | 並び順変更（中央値安い順/高い順・最安都市順・都市数順・五十音順） |

## 既知の限界

- **件数ベース探索の不安定さ**: Booking.com の「N軒が見つかりました」は同一条件でも揺れることがあり、価格上限を上げたのに件数が減る例を確認。5都市（ブダペスト・フンシャル・ミコノス・プーケット・デンパサール）は探索が発散したため、検索結果1ページ目の表示価格の中央値で代用（HTMLで `≈` 表示）。他都市よりやや高めに出る。
- **掲載数が少ない都市**: 71都市が最薄月30軒未満。数軒の増減で中央値が動く。
- **季節変動**: 69都市が年間で2倍以上の変動。年間中央値だけで判断しない。
- **1名利用・税別とは水準が違う**: 2名1室・税込のため、1名税別表示の他ソースより高く出る。
- **星は Booking.com 表示準拠**: 国により実質的な品質水準は異なる。
- **都市選定**: 主要観光・ビジネス都市350件を対象。全都市の網羅ではない。マンダレー（ミャンマー）は4つ星在庫がほぼ無く除外。

## アゴダを採用していない理由

アゴダのGraphQL検索APIは再現に成功し、価格ヒストグラム（実数）・掲載数・座標を1リクエストで取得できることを確認した。しかし都市ID解決で350リクエストを送った時点で `/graphql/search` が502を返し続ける状態になり、40分以上待っても復旧せず、本取得を断念した。

なお唯一取得できたバンコクの値は、税別で ¥11,790。同日のBooking税込 ¥13,900 をタイの税＋サービス料17.7%で割ると ¥11,810 で、ほぼ一致する。**「アゴダが安い」の大半は税表示の差**で説明がつき、同一基準では有意差は確認できなかった。
