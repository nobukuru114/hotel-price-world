## Booking.com リンクの条件

| 項目 | 値 | 場所 |
|---|---|---|
| 日付 | 明日チェックイン・3泊（ブラウザ側で毎回計算） | index.html `bookDates()`／生成ページ `BOOK_JS` |
| 人数・部屋 | 大人1名・1室・子ども0 | `BOOK_OPT`（index.html）／`bookUrl`（build-pages.js） |
| 絞り込み | 掲載数と緯度で3段階に自動調整（全条件だと0件になる都市があるため）<br>・共通: 4〜5つ星・口コミ8.0以上・朝食付き・ホテルのみ・中心3km以内<br>・掲載30軒以上: ＋無料Wi-Fi ＋専用バスルーム ＋ダブルベッド（緯度40度未満なら ＋エアコン）<br>・掲載100軒以上: ＋フィットネス ＋眺望 | `bookFilters()`（index.html と build-pages.js） |
| 表示 | 表の「予約」（条件はツールチップ）・地図の吹き出し・都市/国ページのボタン（条件をボタン下に常時表示） | `bkNote`（tools/i18n/pages.js） |
| 言語 | 言語ごとに切替（ja: `searchresults.ja.html`／en: `searchresults.en-gb.html`） | `booking`（tools/i18n/pages.js） |
| 通貨 | 表示通貨（`cur`）に連動。未選択時は言語の既定通貨 | `defCur`（tools/i18n/pages.js）が既定の正本 |

サイトの価格は「2名1室1泊」基準なので、リンク先（1名・3泊）の表示額とは一致しない。

## 都市の選定基準（2026-09-22 制定）

初版の347都市は「主要な観光・ビジネス都市」を手作業で選んだもので、明文化した基準はなかった。今後の追加は次の基準で行う（追加のみ・既存都市の削除や改名はしない）。

| # | 基準 | 目安 |
|---|---|---|
| 1 | 各国・地域の首都と最大都市 | 未収載の国は首都から |
| 2 | 国際観光客の到着数が多い都市 | 各国観光統計・Euromonitor Top 100 City Destinations に載る都市 |
| 3 | 人口100万人超の都市 | 4つ星が最薄月でも30軒以上あるもの |
| 除外 | 4つ星が最薄月10軒未満、または探索が発散する都市 | 例: マンダレー |

追加手順: `node tools/fetch-city.js --name "Cebu" --country "Philippines" --ja "セブ"` → `node tools/apply-city.js`（DATA追加・ページ生成・slug反映）。

## データ更新のルール

- **都市名 `name` と国名 `c` は変えない**。お気に入り（localStorage の `favCities` / `favCountries`）のキーが `name|c` なので、表記を変えると利用者の★が消える。表記を直したい場合は日本語名 `ja` だけを直す。
- 都市は追加のみ。外す場合も `name|c` を再利用しない。
- 価格の更新は同じキーのレコードの `med/lo/hi/cnt/m/ap/cap` だけを差し替える（`tools/apply-city.js` がそのように動く）。

## 既知の限界

- **件数ベース探索の不安定さ**: Booking.com の「N軒が見つかりました」は同一条件でも揺れることがあり、価格上限を上げたのに件数が減る例を確認。5都市（ブダペスト・フンシャル・ミコノス・プーケット・デンパサール）は探索が発散したため、検索結果1ページ目の表示価格の中央値で代用（HTMLで `≈` 表示）。他都市よりやや高めに出る。
- **掲載数が少ない都市**: 71都市が最薄月30軒未満。数軒の増減で中央値が動く。
- **季節変動**: 69都市が年間で2倍以上の変動。年間中央値だけで判断しない。
- **1名利用・税別とは水準が違う**: 2名1室・税込のため、1名税別表示の他ソースより高く出る。
- **星は Booking.com 表示準拠**: 国により実質的な品質水準は異なる。
- **都市選定**: 主要観光・ビジネス都市350件を対象。全都市の網羅ではない。マンダレー（ミャンマー）は4つ星在庫がほぼ無く除外。

## アゴダを採用していない理由

アゴダのGraphQL検索APIは再現に成功し、価格ヒストグラム（実数）・掲載数・座標を1リクエストで取得できることを確認した。しかし都市ID解決で350リクエストを送った時点で `/graphql/search` が502を返し続ける状態になり、40分以上待っても復旧せず、本取得を断念した。

なお唯一取得できたバンコクの値は、税別で ¥11,790。同日のBooking税込 ¥13,900 をタイの税＋サービス料17.7%で割ると ¥11,810 で、ほぼ一致する。**「アゴダが安い」の大半は税表示の差**で説明がつき、同一基準では有意差は確認できなかった。
