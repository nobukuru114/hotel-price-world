隱私權政策

最後更新：2026年9月23日

1. 基本原則

本站是獨立經營的資訊網站，發布全球各城市四星級飯店房價的彙整資料。我們重視訪客的個人資訊保護，並依下列方式處理相關事宜。

2. 不會蒐集的資訊

本站僅由靜態網頁構成，沒有註冊機制、聯絡表單或留言區。本站不會要求你輸入或傳送姓名、地址、電話號碼或電子郵件地址。

3. 儲存於你瀏覽器中的資料（localStorage）

為了讓網站使用更方便，以下資訊會儲存在你自己的瀏覽器內：

項目用途
favCountries你收藏的國家／地區
favCities你收藏的城市
basemap2你選擇的地圖樣式（自動／標準／淺色／深色）
theme你選擇的顯示模式（自動／淺色／深色）
cur你選擇的顯示幣別
lang你選擇的語言
  • 這些資料只留在你的瀏覽器中，不會傳送給本站或任何第三方。
  • 其中不包含任何可識別你身分的資訊。
  • 你可以隨時在瀏覽器設定中清除此網站的資料。

4. 分析工具

本站發布於 GitHub Pages，GitHub 可能會記錄訪客的 IP 位址。詳情請參閱 GitHub 隱私權聲明。

若未來加入 Google Analytics 等自有的分析工具，我們會更新本頁並明確說明。

5. 廣告

本站目前未刊登任何廣告。若日後刊登第三方廣告服務（如 Google AdSense）的廣告，該服務提供商可能使用 Cookie 依你的興趣顯示廣告。屆時我們會更新本頁，並提供 Google 廣告政策與條款連結及退出個人化廣告的說明。

本站含有連結至 Booking.com 等外部網站。關於這些網站如何處理個人資訊，請參閱其各自的隱私權政策。對於連結網站上發生的任何事情，本站概不負責。

8. 變更

本政策可能未經通知即修訂。修訂內容自本頁公開發布時起生效。
