プライバシーポリシー

最終更新: 2026-09-22

1. 基本方針

当サイト（以下「本サイト」）は、世界各都市の4つ星ホテル価格を集計して公開する個人運営の情報サイトです。利用者の個人情報の保護を重要な責務と考え、以下のとおり取り扱います。

2. 取得しない情報

本サイトは静的なウェブページのみで構成されており、会員登録機能・問い合わせフォーム・コメント欄を設けていません。氏名・住所・電話番号・メールアドレスなどの個人情報を、本サイト上で入力・送信していただくことはありません。

3. ブラウザ内に保存されるデータ（localStorage）

本サイトは、利用者の操作性向上のため、以下の情報を利用者のブラウザ内（localStorage）に保存します。

保存キー用途
favCountriesお気に入り登録した国・地域
favCitiesお気に入り登録した都市
basemap2選択した地図のスタイル（自動／標準／淡色／ダーク）
theme選択した表示モード（自動／ライト／ダーク）
cur選択した表示通貨
lang選択した言語
  • これらのデータは利用者のブラウザ内のみに保存され、運営者を含む第三者に送信されることはありません。
  • 個人を特定できる情報は含みません。
  • ブラウザの設定から本サイトのサイトデータを削除することで、いつでも消去できます。

4. アクセス解析

本サイトは GitHub Pages 上で公開されており、GitHub 社によってアクセス元の IP アドレス等が記録される場合があります。詳細は GitHub プライバシーステートメント をご確認ください。

運営者が独自のアクセス解析ツール（Google アナリティクス等）を導入した場合は、本ページを更新のうえ明記します。

5. 広告配信について

現時点で本サイトは広告配信を行っていません。将来 Google AdSense 等の第三者配信事業者による広告を掲載する場合、当該事業者が利用者の興味に応じた広告を表示するために Cookie を使用することがあります。その際は本ページを更新し、広告 – ポリシーと規約 – Google へのリンクおよびパーソナライズ広告の無効化方法を明記します。

6. 外部サービスへの通信

ページの表示にあたり、以下の外部サービスへ利用者のブラウザから通信が発生します。これらの提供元では、通信元 IP アドレス等が記録される場合があります。

提供元用途
cdnjs (Cloudflare)地図ライブラリ Leaflet の配信
Esri / ArcGIS Online地図タイル（淡色スタイル）
OpenStreetMap Foundation地図タイル（標準スタイル）

7. 外部リンク

本サイトは Booking.com 等の外部サイトへのリンクを含みます。リンク先における個人情報の取り扱いについては、各サイトのプライバシーポリシーをご確認ください。リンク先で生じた損害について、運営者は責任を負いません。

8. 改定

本ポリシーは予告なく改定する場合があります。改定後の内容は本ページに掲載した時点で効力を生じます。

9. お問い合わせ

本ポリシーに関するお問い合わせ先は 運営者情報 に記載しています。
